用語ドリル資格の用語を、すきま時間に覚える無料の単語帳

資格の試験に出てくる用語を、カードと4択クイズで覚える単語帳のサイトです。どのサイトも無料・登録不要で、スマホでもパソコンでも使えます。いま2つのサイトで、あわせて1010語の用語を公開しています。

  • カード意味を読んで用語を思い出し、裏返して確かめる
  • 4択クイズ同じ分野のまぎらわしい用語から選ぶ
  • 書いて答える説明を読んで、用語を入力する
  • 復習まちがえた用語だけを集めて解き直す

このサイトについて

用語ドリルは、個人で開発・運営している学習サイトの入り口です。用語の説明は、運営者が AI の支援を受けて作成し、内容を確認したうえで掲載しています。試験の範囲や日程などの最新の情報は、各試験の実施団体のサイトで確認してください。

進み具合は、使っているブラウザの中にだけ保存されます。サイトごとに別々に記録されます。

サイト一覧 運営者情報・プライバシーポリシー お問い合わせ

基本情報技術者試験・ITパスポート試験は、独立行政法人 情報処理推進機構（IPA）が実施する国家試験です。

Amazon Web Services、AWS、および関連する名称は、Amazon.com, Inc. またはその関連会社の商標です。

生成AIパスポートは一般社団法人生成AI活用普及協会（GUGA）が、G検定は一般社団法人日本ディープラーニング協会（JDLA）が実施する試験・検定です。

簿記検定（商工会議所簿記検定試験）は、日本商工会議所と各地の商工会議所が実施する検定です。

国内旅行業務取扱管理者試験は、一般社団法人 全国旅行業協会が実施する国家試験です。

このサイトと各学習サイトは個人が運営しており、上記の試験の実施団体・企業とは関係ありません。
